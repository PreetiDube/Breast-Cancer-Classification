Breast Cancer Classification

An end-to-end educational machine learning project using Python and Logistic Regression to classify samples from the Wisconsin Diagnostic Breast Cancer dataset.

01. About the Project

Turning diagnostic data into a machine learning classification result.

Project Objective

Explore diagnostic features and train a Logistic Regression model to classify dataset samples as malignant or benign. This project demonstrates a standard machine learning workflow.

What I Built

  • Exploratory data analysis
  • Stratified training and testing split
  • Feature scaling and model training
  • Classification report and confusion matrix

03. Methodology

The workflow followed in the notebook.

  1. Load and inspect the diagnostic dataset.
  2. Explore the data and examine feature relationships.
  3. Split data into stratified training and test sets.
  4. Scale features as part of the model pipeline.
  5. Train the Logistic Regression classifier.
  6. Evaluate performance with accuracy, a classification report, and a confusion matrix.
